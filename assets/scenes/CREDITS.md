# Backdrop photographs

The places you climb through are photographs. Every one is either in the
public domain or under a licence that asks only for credit; nothing here
carries a ShareAlike term, because cropping a photo to fit the screen is an
adaptation and that obligation would follow the crop into the app.

`tools/fetch-photos.mjs` re-checks each licence against Wikimedia Commons
every time it runs, and refuses to write a file whose licence has changed.
